2. Definition

Find the common rule that maps an input grid to an output grid, given the examples below. Generate a python script that takes a grid as input and transforms it according to the this rule. Anticipate that this program will be applied to several grids, not only the shown test grid.

Your script must define exactly one callable entrypoint: def solve(grid): where `grid` is passed as a list of lists of integers (list[list[int]]) and the function returns the transformed grid in the same format.

def solve(grid):
    rows, cols = len(grid), len(grid[0])
    # Find 2 positions in bottom row
    twos = [c for c in range(cols) if grid[rows-1][c] == 2]
    # Find 5 positions
    fives = [(r, c) for r in range(rows) for c in range(cols) if grid[r][c] == 5]
    
    # Each 5 is associated with nearest 2-column; the line goes from 5's row down to row 9,
    # but shifted: the 2-column line goes from bottom up, and at the 5's row it shifts to the 5's column
    
    result = [[0]*cols for _ in range(rows)]
    
    for five_r, five_c in fives:
        # Find nearest 2-column
        best = min(twos, key=lambda tc: abs(tc - five_c))
        # Draw 2s: from row 0 to five_r at column (best + (five_c - best)) with offset
        # Looking at example: the line is at the 2's column below the 5, and at 5's column+1 (or shifted) above
        # Actually: below 5 (inclusive of 5's row+1 to row 9): column = best
        # Above 5 (row 0 to 5's row): column = best + (five_c - best + 1) ... let me re-examine
        
        # Ex1: 5 at (3,6), 2 at col 6. Output: col 7 has 2s rows 0-3, col 6 has 2s rows 4-9
        # So above: best+1=7, below (inclusive 5 row+1): best=6
        # Wait row 3 has 2 at col 7 too. So rows 0 to 3: col 7, rows 4-9: col 6
        
        # Ex1: 5 at (5,2), 2 at col 1. Above rows 0-5: col 2, below rows 6-9: col 1
        # So above (0 to five_r): five_c, below (five_r+1 to 9): best? No, col1 has 2s everywhere rows 0-9
        # Hmm, col 1 has 2s all rows. So that 2-column is unaffected? 
        # Wait the 2 at col1 maps to 5 at (5,2). The shift: above rows 0..5 at col 2, below rows 6..9 at col 1
        
        # Pattern: from bottom (row 9) up to five_r+1: draw at column=best. From five_r up to 0: draw at column=five_c (if five_c != best) or five_c+1?
        # Ex1 5@(3,6) best=6: above col=7 (five_c+1), below col=6. Hmm
        # Ex1 5@(5,2) best=1: above col=2 (five_c), below col=1 (best)
        
        # above column = best + (five_c - best) = five_c... no for first case five_c=6, above=7
        # Offset = five_c - best. For (3,6)->best=6, offset=0, above=7=best+1
        # For (5,2)->best=1, offset=1, above=2=best+1... wait that's also best+1=2=five_c
        # Ex2: 5@(3,5) best=4, above col=5=best+1=five_c. 5@(5,1) best=1, above=2=best+1
        # 5@(6,8) best=7, above=8=best+1=five_c
        
        # So: above (rows 0 to five_r): column best+1, below (rows five_r+1 to 9): column best
        
        above_col = best + 1 if five_c >= best else best - 1
        below_col = best
        
        for r in range(0, five_r + 1):
            if 0 <= above_col < cols:
                result[r][above_col] = 2
        for r in range(five_r + 1, rows):
            result[r][below_col] = 2
    
    # Place 5s
    for five_r, five_c in fives:
        result[five_r][five_c] = 5
    
    return result
